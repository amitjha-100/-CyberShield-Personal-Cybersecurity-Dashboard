Security Habits to Remember

Small habits can make a meaningful difference.

01

Use unique passwords

Use a password manager to generate and store unique passwords.

02

Enable MFA

Use multi-factor authentication, preferably phishing-resistant options.

03

Verify links

Check the actual domain and confirm unexpected requests independently.

04

Update your devices

Install operating system, browser, and application security updates.
