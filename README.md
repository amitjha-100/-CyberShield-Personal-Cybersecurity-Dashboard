

# 🛡️ CyberShield — Personal Security Dashboard

CyberShield is a beginner-friendly cybersecurity awareness dashboard built
using HTML, CSS, and JavaScript.

The project combines front-end web development with basic cybersecurity
education in a clean, responsive interface.

## Features

- Responsive dark-themed dashboard
- Password strength estimation
- Show/hide password input
- Basic suspicious URL heuristic checks
- Cybersecurity awareness tips
- Accessible form feedback
- No external APIs or frameworks required

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- DOM manipulation
- Regular expressions
- URL parsing

## Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/amitjha-100/cybershield-dashboard.git
   ```

2. Open the project folder:

   ```bash
   cd cybershield-dashboard
   ```

3. Open `index.html` in your browser.

You can also open the folder in Visual Studio Code and use Live Server.

## Limitations

This project is intended for learning and demonstration.

- Password results are estimates based on simple rules.
- The URL checker does not query threat intelligence databases.
- A URL with no warnings is not necessarily safe.
- The application does not store passwords or send them to a server.
- The project does not perform malware scanning or penetration testing.
